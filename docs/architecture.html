1. 全体像

Browser は Nuxt Worker のみに到達。業務 API の本体は Go。MCP は任意の別入口。

公開Nuxt Worker（OAuth・session・proxy）
非公開Go API / google-worker / advice / cleanup
任意MCP。Web と独立した stdin/stdout
データPostgreSQL。Domain 規則は Transport に置かない

4. 認証と API 転送

sequenceDiagram
  participant B as Browser
  participant N as Nuxt server
  participant G as Google
  participant A as Go API
  B->>N: GET /auth/login
  N->>G: Authorization Code PKCE
  G->>N: /auth/callback
  N->>A: /internal/auth/bootstrap
  N-->>B: session cookie
  B->>N: /api/v1/tasks
  N->>A: /v1/tasks Binding header
  A-->>B: JSON via Nuxt

secret は runtimeConfig.public に置かない。NUXT_GOOGLE_CLIENT_SECRET は callback のサーバー POST のみ。

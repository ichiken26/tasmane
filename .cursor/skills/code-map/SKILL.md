# Code Map Rule

目的: コード注釈と相関図の手順固定。
対象: 関数コメント追加、処理単位スコープの注釈、ファイル/関数相関の MD + HTML 書き出し。

依頼の正本（改変しない）:
- 全てのファイルに関数ごと、処理単位スコープごとに簡潔に何を行っているものか１文で簡潔に体言止めでコメントを書いて
- 文末の。は不要
- すべてのファイルや関数の相関関係やをmdテキストや必要に応じてMermaidを用いて書き出し、ビジュアルに示すように
- 同様の内容をHTMLとしても書き出すように

文体（エージェント応答）:
- 文章にしない
- 名詞句・体言止め・矢印を優先
- `します / しました / 以下に示します` を避ける

## Scope

- コメント追加と相関ドキュメントのみ
- ロジック・識別子・設定値・SQL 中身は変更しない
- 大きい木は層ごとに並列。重複編集しない

## 対象 / 除外

対象:
- ソース `.go` `.ts` `.vue` `.py` `.sh` `.css`
- 設定コメント可 `.yml` `.yaml` `.jsonc` `Dockerfile` `.sql`

除外:
- `node_modules/` `.nuxt/` `.output/` `dist/`
- 生成物 `**/worker-configuration.d.ts`
- `.env` `.env.*`（`.env.example` は可）
- `package-lock.json`
- コメント非対応 JSON（`package.json`、`mcp/tools.json`、schema JSON）

## コメント規則

- 日本語
- 体言止め（名詞で終わる）
- 必ず1文
- 文末の「。」は付けない
- 各関数・メソッド・ハンドラ・テスト関数の直上に1行
- 関数内の独立処理単位（検証、規則適用、永続化、外部呼び出し、大きな分岐塊）にも1行
- 大きな struct / interface / const ブロックの直上にも1行
- import にはコメント不要
- 既存の英語説明は同じ意味の体言止め日本語へ置換可
- Vue template の大きな区画は `<!-- 体言止め -->`
- SQL は `--`、shell/yaml は `#`、CSS は `/* */`

Good:
- `// タスク状態遷移のドメイン規則`
- `// 完了条件の検証`
- `<!-- Dashboard 本体 -->`

Bad:
- `// タスクを遷移する。`
- `// Transition the task.`
- `// この関数は状態を更新します`

言語別:
- Go/TS: `//`
- Vue script: `//` / template: `<!-- -->`
- Python/shell/yaml: `#`
- CSS: `/* */`

## 相関ドキュメント

既定パス:
- `docs/architecture.md`
- `docs/architecture.html`

必須セクション:
1. 全体像（公開面 / 非公開面 / データ / 外部）
2. ランタイムプロセス表
3. 層依存
4. 認証と転送
5. ファイルカタログ（ソースファイルを層ごとに表へ）
6. 関数相関（機能別。主要 call chain）
7. 契約ファイルの位置
8. デプロイ相関
9. 生成物・秘密情報は対象外と明記

図:
- 全体・層・認証シーケンス・主要ユースケースは Mermaid
- 全関数を1枚の図にしない。機能別に分割
- HTML は MD と同内容。Mermaid CDN で描画。サイドナビ付き
- ノード ID は英数字。予約語を ID にしない

## 手順

1. 対象ファイル一覧（除外を先に落とす）
2. 層ごとにコメント追加（ロジック変更なし）
3. 入口・層・主要関数の call chain を収集
4. `docs/architecture.md` 書き出し
5. 同内容を `docs/architecture.html` 書き出し
6. 代表ファイルでコメント規則（体言止め・「。」なし）を抜き取り確認

## Output

```md
実装 ->

変更 ->
- `<file>`: 関数・処理単位コメント
- `docs/architecture.md`: 相関 Markdown
- `docs/architecture.html`: 相関 HTML

確認 ->
- コメント規則: pass / fail
- HTML をブラウザで開く: 未実行 / 済み

除外 ->
- <触らなかった生成物・秘密ファイル>

未対応 ->
- <あれば>
```

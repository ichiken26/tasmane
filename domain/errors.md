# Domain Error Contract

Recommended stable error codes:

- TASK_INVALID_TRANSITION
- TASK_NOT_COMPLETABLE_DESCENDANT
- TASK_NOT_COMPLETABLE_CONFIRMATION
- TASK_PARENT_CYCLE
- TASK_PARENT_GENRE_MISMATCH
- TASK_DEPENDENCY_CYCLE
- TASK_DEPENDENCY_GENRE_MISMATCH
- TASK_VERSION_CONFLICT
- TASK_TYPE_NOT_ALLOWED_FOR_GENRE
- TASK_TYPE_IN_USE
- GENRE_IN_USE
- GENRE_MOVE_DEPENDENCY_CONFLICT
- GOOGLE_SYNC_CONFLICT
- GOOGLE_SYNC_FAILED
- GOOGLE_SYNC_ALREADY_RUNNING

HTTP mapping guideline:
- validation: 422
- optimistic/domain conflict: 409
- unauthenticated: 401
- forbidden: 403
- not found: 404
